# Your branding

Copy this folder to `custom/` (or point `KONVENE_CUSTOM_DIR` at another folder) and rebuild.
Nothing here is needed; add only what you want to change.

| File | What it does |
|---|---|
| `custom.css` | Loads after the built-in styles. Change the colour tokens, or anything else. |
| `logo.svg` | Replaces the logo everywhere (nav, footer, pre-join page, call). Square works best. |
| `favicon.svg` | The browser tab icon. |
| `apple-touch-icon.png` | 180 x 180, for "Add to Home Screen". |
| `og-image.png` | 1200 x 630, the picture shown when someone shares your link. |
| any other file | Copied over the file with the same name in the built site. |

The name comes from `KONVENE_NAME`, not from this folder. See [docs/customising.md](../docs/customising.md).
